一句话原理

和声只有两件事：选对音（你唱的音在当下和弦里）和守住音（主旋律在耳边时不被带走）。四类方法按选音的难度排：甲类不用选音，乙类只选一个音，丙类的音别人已经选好，丁类才自己选、而且只在一个位置选。

类第二声部唱什么核心能力
甲 同一条旋律和主旋律一样，只是时间、音区、范围不同守住进入点和收音点
乙 一个不动的音一个安全音或根音，长唱或短唱对着旋律守住一个音

五个开关

时间差（同时 / 晚进入 / 空隙里 / 整句错开）、音区（同度 / 八度 / 上方 / 下方）、范围（整段 / 整句 / 句尾 / 一个长音）、唱什么（歌词 / wu / ah / mm / 状声词）、长短与音量（越不确定越短越轻；音量是主旋律的六七成）。

安全音

整首歌结尾落地的音叫 do（小调叫 la），往上数第五个音叫 sol（小调 mi）。两个都是安全音，sol 更保险；酸了换另一个或停。本工具每首歌的安全音显示在顶部。

怎么练（单人）

  1. 示例页：先“只有和声”听三遍，再“旋律＋和声”，看卷帘上红色的地方。
  2. 练习页：戴耳机、开麦克风。参考音量 100% 跟唱 → 60% → 30% → 0。
  3. 被带跑：开右声道参考，主旋律音量调到 30%，速度降 20%。
  4. 连续三遍 85% 以上，进入卡片上写的下一个技巧。
  5. 角色互换：你唱旋律、机器唱和声，用来体会“对调”和两条线的关系。
